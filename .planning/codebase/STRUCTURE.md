**Variables:**
- `mlos_df` — MLoS settlement data (primary table)
- `takeoff_df` — Takeoffpoint reference data
- `checks` — List of check result dicts (output of QC engines)
- `details` — DataFrame of failing rows (output of QC engines)
- `mlos_checks`, `settlement_checks`, `tp_checks`, `boundary_checks` — Check results per layer
- `mlos_detail`, `settlement_detail`, `tp_detail`, `boundary_detail` — Issue rows per layer
- `schema_checks`, `schema_detail` — Schema validation results
- `weighted_score` — Overall QC score (0–100%)

**Constants:**
- `MLOS_VIEW` — SQLite view name for settlements (`"master_list_settlement_update_view"`)
- `TAKEOFF_VIEW` — SQLite view name for takeoffpoints (`"mlos_takeoffpoint_view"`)
- `MLOS_REQUIRED_COLS` — Set of 43 required MLoS columns
- `TAKEOFF_REQUIRED_COLS` — Set of 4 required Takeoffpoint columns
- `YN_NA_COLS` — Flag column names (8 total: highrisk, slums, etc.)
- `LAYER_WEIGHTS` — Dict of weight per QC layer (schema 10%, mlos 40%, etc.)
- `BOUNDARY_REF_PATH`, `BOUNDARY_BBOX_PATH` — File paths to ward reference data

## Where to Add New Code

**New QC Rule:**
1. Identify layer: Schema / MLoS / Settlement / Takeoffpoint / Boundary
2. Add to appropriate `run_XYZ_qc()` function
3. Pattern: Call helper `add(rule_num, rule_name, description, mask, extra_cols)`
4. Location depends on layer:
   - Schema: `app.py:232-278`
   - MLoS: `app.py:805-965`
   - Settlement: `app.py:539-633`
   - Takeoffpoint: `app.py:969-1012`
   - Boundary: `app.py:383-536`

**New Auto Correct Rule:**
1. Add correction logic to `auto_correct_mlos()` (`app.py:700-784`)
2. Build mask for rows needing correction
3. Apply correction
4. Log correction with row count
5. Example: Lines 710-719 (flag columns NULL → NA)

**New Tab/UI Feature:**
1. Create new `tab_X` in tabs list (`app.py:1499-1508`)
2. Add logic inside `with tab_X:` block
3. Populate with `st.dataframe()`, `st.download_button()`, etc.
4. Example: Tab 1 (Auto Correct) is `app.py:1589-1629`

**New Report Format:**
1. Create new builder function `build_XYZ()` alongside existing report builders (`app.py:280-1154`)
2. Use openpyxl for styling (colors, fonts, borders)
3. Return `BytesIO()` object containing Excel bytes
4. Add download button in appropriate tab
5. Example: `build_excel_report()` (`app.py:1015-1154`)

**New Data Format Support (not CSV/Excel/SQLite):**
1. Add to `get_uploaded_data()` dispatch logic (`app.py:157-204`)
2. Create new `load_format()` function
3. Return (mlos_df, takeoff_df) tuple
4. Add file type to uploader `type` parameter (`app.py:1178-1180`)

**New QC Layer (6th layer):**
1. Create `run_layer6_qc(mlos_df, takeoff_df, ...)` following pattern
2. Add to orchestration loop (`app.py:1364-1426`)
3. Update progress bar thresholds
4. Add to `all_checks` concatenation (`app.py:1439`)
5. Add weight to `LAYER_WEIGHTS` dict (`app.py:1451-1457`)
6. Add tab or display section to results UI
7. Update email summary in `send_qc_email()` (`app.py:658-673`)

**New Email Recipient:**
1. Hard-coded recipients in `send_qc_email()` (`app.py:644-647`)
2. Edit `TO` or `CC` lists
3. Rebuild and redeploy

**New Ward Reference Data (update boundary checks):**
1. Replace `ward_boundary_ref.csv` or `ward_boundary_bbox.csv` in repo root
2. Ensure columns match expected schema:
   - `ward_boundary_ref.csv`: `state_code`, `state_name`, `lga_code`, `lga_name`, `ward_code`, `ward_name`
   - `ward_boundary_bbox.csv`: `ward_code`, `min_lon`, `max_lon`, `min_lat`, `max_lat`
3. Commit updated CSV files
4. Cache is invalidated automatically next Streamlit run

## Special Directories

**No build output directory** — Streamlit caches in `.streamlit/` (user-specific, not committed)

**No test directory** — Currently no unit tests; manual testing via Streamlit browser

**No venv/packages directory** — `pip install -r requirements.txt` installs to system/virtual environment

## Key Dependencies

**Core:**
- `streamlit` (>=1.32.0) — Web framework, UI components, session state, caching
- `pandas` (>=2.0.0) — Data manipulation, vectorized operations, DataFrame handling
- `openpyxl` (>=3.1.0) — Excel file generation and styling
- `xlrd` (>=2.0.1) — Reading legacy Excel formats (.xls)
- `numpy` — Vectorized math (Haversine distance calculation)
- `sqlite3` — Standard library, SQLite connection/query
- `smtplib` — Standard library, email sending
- `openpyxl.styles` — Excel cell formatting

**Installed as dependencies:**
- `python-dateutil`, `tzlocal` (via pandas)
- `Pillow`, `charset-normalizer`, `click`, etc. (via streamlit)
