  <action>
    Write `scripts/verify_history_scrub.py` using only the standard library plus `git` through
    `subprocess` — no new runtime dependency, and it must not appear in `requirements.txt`.

    `build_address_pattern(domain)` compiles a conventional local-part pattern followed by the
    escaped domain. `main` imports `qc.auth_domain.ALLOWED_DOMAIN` and passes it in. Importing the
    constant rather than transcribing the four addresses is the whole design: the phase is
    removing those strings from the repository, and a verifier that carries a copy of them
    reintroduces exactly what it is meant to prove absent. It also means the verifier keeps
    working if a fifth address is discovered in history that nobody enumerated — which is why
    plan 04-06's preparation task derives the replacement list from history with this same
    pattern instead of from a hand-written list.

    Search **every ref**, not the checked-out branch. Enumerate commits with
    `git rev-list --all` and search their content; a practical implementation is
    `git log --all -p` streamed through the pattern, plus `git grep` across the commit list for a
    second, independent confirmation. An address surviving on an unmerged branch or an old tag is
    still an address in the repository's history, and a HEAD-only check is the most common way
    this requirement gets falsely marked done.

    Report, don't just exit: print the count of distinct offending addresses, and for each, at
    least one ref or commit where it was found, so a failure tells the operator where to look.
    Exit non-zero when any offender is found. Add a `--expect-nonzero` flag that inverts the exit
    condition for the baseline run, and make the no-repository case exit non-zero with a named
    reason so a mis-invoked verifier can never be mistaken for a clean result.

    Write `tests/test_history_scrub_verifier.py` covering every bullet in `<behavior>` with no
    git repository and no network — feed synthetic text to `build_address_pattern` and
    `find_offending_addresses`. Include the two non-vacuity assertions: a synthetic address
    assembled from `ALLOWED_DOMAIN` IS matched, and the redaction placeholder plan 04-02
    introduced is NOT matched. Include a test that the script's own source contains no address
    literal, mirroring the guard plan 04-02 installed.
  </action>
