<objective>
Build the fixture corpus this phase's tests run against, and capture — from the current,
un-refactored `app.py` — a golden record of what all six relocating functions produce. Every
later plan in this phase compares its extracted module against this record.

Purpose: this phase claims "no new checks and no changed verdicts". Six functions and roughly
600 lines move across a package boundary with no test suite behind them today. `01-RESEARCH.md`
Pitfall 1 names the exact failure this guards: a dropped tilde, or an `.isin()` turned
`.isna()`, during a copy-paste flips a check's result, nobody notices, and the tool starts
calling a dirty file clean. That is a direct hit on this project's core value.
Output: a shared fixture module, pytest fixtures, a capture script, the golden JSON it produces,
and a standing test that the golden file still describes the pre-fix state.
</objective>
