<objective>
Pin the dependency set so every later fix in this phase and in Phases 2-7 is written and
tested against one known pandas, and stand up the pytest harness the rest of this phase's
standing tests will live in.

does not declare `numpy` at all, even though `numpy` is imported at `app.py:540`. The live
environment resolved 3.0.2 by accident. Until this closes, every subsequent correctness fix is
verified against whatever pandas resolved that day.

a `pytest.ini` so `pytest` finds `tests/` with no flags, and a standing test that fails the
moment the resolved environment stops matching the declaration.
</objective>
