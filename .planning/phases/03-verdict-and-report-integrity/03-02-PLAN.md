<objective>
Make the downloaded Excel report describe every layer that ran and derive its cover verdict
from all five of them. Closes VERDICT-01 and VERDICT-02 (both F1 — the report cover summed
only two layers, so a file failing only Boundary downloaded as CLEAN) and ENGINE-08 (F12 —
per-cell styling on bulk sheets).

The workbook builder moves out of app.py into `qc/report.py`, where it is importable and
unit-testable without a Streamlit runtime, and reads only the `QcSummary` object plan 01
built. Its single call site in app.py's Generate Report tab is rewired accordingly.

Purpose: a filed report is the artefact that outlives the session. A cover that says CLEAN
over a failing file is the trust violation the project's core value names.
Output: `qc.report.build_workbook` and `qc.report.summary_rows`; a ten-sheet workbook whose
cover carries the verdict and score only; plain-value detail and raw sheets.
</objective>
