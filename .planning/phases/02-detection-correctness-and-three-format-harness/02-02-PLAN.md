<objective>
Close INTEG-02: a blank value can no longer satisfy a cross-table match rule, and a blank gets its
own registered finding rather than being folded into a match failure.

Purpose: `set(takeoff["name"].dropna().str.strip())` cannot drop an empty string, because
`keep_default_na=False` means a CSV or XLSX blank arrives as `""` rather than NaN. So `""` enters
the valid-target set and a blank matches a blank — defect F9. Two blanks facing each other across a
join currently read as a successful reconciliation.

Output: six new registered checks — `2.missing`, `3.missing`, `4.missing`, `TP2.missing`,
`TP3.missing`, `TP4.missing` — with the six existing match masks rebuilt so an absent source cell
is excluded from the match rule instead of double-counted, the sidebar reference updated in the
same commit, and two new fixture builders plus a test that proves a blank is actually detected
rather than merely reported as zero.
</objective>
