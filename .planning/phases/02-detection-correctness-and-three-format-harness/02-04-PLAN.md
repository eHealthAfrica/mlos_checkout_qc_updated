<objective>
Close the presentation half of INTEG-03: apply the normalisation helper once at load on every path
that carries officer-supplied headers, and show the officer which columns were renamed — on screen
and in the downloadable report.

Purpose: plan 03 built the helper and the `S3` check but nothing calls the helper yet, so F7 is
still live and `S3` can only ever report zero. This plan wires the load path and closes the loop
back to the officer, which is the half of INTEG-03 the requirement states as "renames are reported
to the officer".

Output: `qc.columns.normalize_columns` invoked on the MLoS frame, the same-upload Takeoffpoint frame
and the separately uploaded Takeoffpoint file; two new session-state keys carrying the rename map
and the collision groups across reruns; an on-screen rename panel; a Columns Renamed sheet in the
QC report; and a test proving the F7 contrast — that a non-canonically spelled header now resolves
to its rule instead of satisfying the schema check and disappearing.
</objective>
